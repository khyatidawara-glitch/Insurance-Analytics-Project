# Branch Analytics

## Overview
This project analyzes insurance branch performance, revenue generation, account executive performance, budgets, opportunities, invoices, fees, and brokerage.

## Tools Used
- Microsoft Excel
- Power BI
- Tableau
- MySQL

## Data Tables
- Dim_account_exe
- Opportunity
- Meeting
- Invoice
- Individual Budgets
- Fees
- Brokerage

## KPIs
- Renewal Achievement Percentage
- Branch Revenue Comparison
- Branch-wise Open Opportunity Count
- Top 10 Won Opportunities
- Average Invoice Value
- Revenue per Client

## Objective
To analyze branch and account executive performance and identify revenue trends, opportunity status, and budget achievement.

## Note
SQL calculations and dashboard figures are subject to final validation.
